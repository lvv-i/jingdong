## 一、环境说明

由于沙箱环境无法安装 MySQL 8 服务器，采用 **H2 内嵌数据库（MySQL 兼容模式）** 替代方案：

| 项 | 值 |
|---|---|
| 数据库 | H2 2.2.224（`MODE=MySQL`） |
| 持久化 | 文件模式 `./data/jd_shop`（重启数据不丢） |
| 端口 | `localhost:8080` |
| 启动命令 | `java -jar backend/target/jd-shop-1.0.0.jar --spring.profiles.active=h2` |
| H2 控制台 | http://localhost:8080/h2-console |

**适配变更（`pom.xml` + `application-h2.yml` + `sql/h2-schema.sql` + `sql/h2-seed.sql`）：**
- 添加 `com.h2database:h2` 运行时依赖
- H2 JDBC URL 启用了 `MODE=MySQL;DB_CLOSE_DELAY=-1;DATABASE_TO_UPPER=false`
- `spring.sql.init.mode=always` 每次启动自动执行建库建表 + 种子数据
- H2 schema 适配：`TINYINT→SMALLINT`、去除 `ENGINE=InnoDB`、去除 `ON UPDATE CURRENT_TIMESTAMP`、去除列注释

**原生 MySQL 8 环境（可选后续部署）：**
- 原始 `application.yml` 保留 MySQL 配置（profile 默认值）
- 原始 `backend/sql/20260812_001_schema.sql` 和 `002_seed.sql` 保留，可直接在 MySQL 8 执行
