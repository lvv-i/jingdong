## 1. 页面清单

| 编号 | 页面 | 说明 |
|---|---|---|
| D-P01 | 首页 | 轮播、类目入口、热销商品（与 B-P01 同数据） |
| D-P02 | 分类页 | 类目树导航 + 商品列表 |

| D-P09 | 登录/注册 | 账号密码 + 短信验证码登录 |

## 2. 与网页端差异需求（提交给 A）

| 序号 | 差异 | 说明 | 优先级 |
|---|---|---|---|
| 1 | 短信验证码登录 | 移动端主推：发送验证码 → 验证码登录（demo 固定码 123456） | 高 |
| 2 | 商品瀑布流分页 | 移动端用 page/pageSize 分页即可，无需特殊接口 | - |
| 3 | 消息推送 | 阶段二评估，本阶段用轮询 GET /api/notifications | 低 |

## 3. 交互约定

1. 移动端与网页端共用同一套 API 与状态机，不做差异化接口（除验证码登录）。
2. 按钮显隐同样依赖后端状态（PENDING_PAY 显示支付/取消等）。
3. 未登录可浏览，下单/购物车操作前引导登录（code=1002 跳登录页）。
