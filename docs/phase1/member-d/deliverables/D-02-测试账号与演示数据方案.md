## 2. 固定演示数据

| 类别 | 数据 | 说明 |
|---|---|---|
| 类目 | 数码家电 / 服饰鞋包 / 食品生鲜 / 家居日用（各含 2-3 子类目） | 三层以内类目树 |
| 商品 | 每类目 3-5 个 ON_SALE 商品（含主图/详情/库存） | 覆盖价格排序、销量排序演示 |
| 订单 | 预置 user001 各状态订单各 1 条（PENDING_PAY/PAID/SHIPPED/COMPLETED/CANCELLED） | 演示状态流转 |
| 售后 | 预置 1 条 REFUNDING 售后单（merchant001 处理）、1 条 ADMIN_INTERVENED（admin001 裁决） | 演示完整售后链 |
| 通知 | 预置 3-5 条系统通知 | 演示已读/全部已读 |
| 支付 | 模拟支付：订单超时默认 30 分钟，演示时建议配置为 2 分钟 | 快速演示超时取消 |

## 3. 测试基线约定

1. 测试用例按 T1 状态机设计：合法流转（正向）、禁止流转（负向，期望 1001/4002/5005）、边界（库存 0、金额超实付）。
2. 权限测试按 C-02 权限矩阵：越权访问期望 1003、未登录期望 1002。
3. 联调环境：`http://localhost:8080`，B/C/D 各自前端代理统一指向该地址。
4. 数据库初始化脚本由 A 在第二阶段提供（含种子数据，与本方案一致）。
