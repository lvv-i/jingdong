## 2. 关键交互与状态依赖（读 A 状态机）

| 页面 | 操作 | 状态依赖（订单/售后状态） |
|---|---|---|
| 订单列表/详情 | 支付按钮 | 仅 PENDING_PAY 显示 |
| 订单列表/详情 | 取消按钮 | 仅 PENDING_PAY 显示 |
| 订单列表/详情 | 确认收货按钮 | 仅 SHIPPED 显示 |
| 订单列表/详情 | 评价入口 | 仅 COMPLETED 且未评价显示 |
| 售后列表 | 撤销按钮 | 仅 REFUNDING 显示 |
| 售后列表 | 申请介入按钮 | 仅 MERCHANT_REJECTED 显示 |

> 前端不做状态机校验，全部依赖后端返回状态控制按钮显隐；非法操作后端返回 1001/4002/5005，前端 toast 展示 message。

## 3. 统一交互约定

1. 登录后请求统一带 `Authorization: Bearer <token>`。
2. 列表页一律分页（page/pageSize），数据取 `data.list` + `data.total`。
3. 业务错误 HTTP 200，前端按 `code` 分支提示；`code=1002` 跳登录页。
4. 提交类按钮点击后置 loading，防止重复提交（后端 1006 幂等兜底）。
