## 2. 数据范围矩阵

| 角色 | 数据范围 | 后端校验依据（T4） |
|---|---|---|
| USER | 仅本人：订单/地址/购物车/售后/通知 | `user_id == UserContext.userId` |
| MERCHANT | 仅本店：商品/订单/售后/店铺 | `merchant_id == UserContext.shopId` |
| ADMIN | 全局 | 无需资源归属校验，敏感操作写 audit_logs |

## 3. 越权返回约定

| 场景 | 错误码 | message |
|---|---|---|
| 未登录访问受保护接口 | 1002 | 未登录或登录已过期 |
| 角色不匹配（USER 访问 /api/merchant/**） | 1003 | 无权限访问 |
| 资源不属于当前用户/店铺 | 1003 | 无权限访问该资源 |
| 商家无店铺/店铺未审核 | 6001/6002/6003/6004/6005 | 按具体状态提示 |
| 管理员访问不存在的资源 | 1004 | 资源不存在 |

## 4. 与 T4 对齐确认

- ✅ 拦截矩阵三前缀 `/api/**`、`/api/merchant/**`、`/api/admin/**` 与本矩阵一致
- ✅ 白名单 5 项（注册/登录/类目/商品列表/商品详情）与本矩阵"匿名"列一致
- ✅ 数据权限 10 条校验清单全部落在本矩阵数据范围列
