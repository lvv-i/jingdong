# C-01 后台页面清单（商家后台 + 管理员后台）

> 成员 C（后台端）｜ 版本 v1.0 ｜ 日期 2026-08-12
> 依据：`../member-a/deliverables/01-状态机枚举表.md`（v1.0）、`04-JWT鉴权与RBAC方案.md`（v1.0）

## 1. 商家后台页面清单

| 编号 | 页面 | 路径 | 关键内容 |
|---|---|---|---|
| C-M01 | 店铺仪表盘 | /merchant/dashboard | 今日订单数、销售额、待发货数、待处理退款数 |
| C-M02 | 商品管理 | /merchant/products | 商品列表（按状态 Tab）、新建/编辑、提交上架审核、下架 |
| C-M03 | 库存管理 | /merchant/stock | 库存查询、修改（并入商品管理可快捷改库存） |
| C-M04 | 订单处理 | /merchant/orders | 订单列表、发货（填运单号）、订单详情 |
| C-M05 | 售后处理 | /merchant/refunds | 退款列表、同意/拒绝（填回复） |
| C-M06 | 店铺设置 | /merchant/shop | 店铺资料、入驻审核状态展示 |

## 2. 管理员后台页面清单

| 编号 | 页面 | 路径 | 关键内容 |
|---|---|---|---|
| C-A01 | 审核中心 | /admin/audit | 商家入驻审核（通过/驳回）、商品上架审核（通过/驳回） |
| C-A02 | 类目管理 | /admin/categories | 类目树增删改查、启停用 |
| C-A03 | 商品巡检 | /admin/products | 全局商品列表、强制下架 |
| C-A04 | 商家管理 | /admin/merchants | 商家列表、状态查看 |
| C-A05 | 用户管理 | /admin/users | 用户列表、禁用/启用 |
| C-A06 | 争议处理 | /admin/refunds | 平台介入退款裁决（同意退款/驳回关闭） |
| C-A07 | 日志统计 | /admin/logs | 审计日志查询；全局统计看板 |

## 3. 后台交互约定

1. 商家登录后接口前缀 `/api/merchant/`，管理员前缀 `/api/admin/`，均带 Bearer token。
2. 所有状态操作按钮按状态机显隐（如仅 PENDING_AUDIT 商家显示"通过/驳回"按钮）。
3. 审核类操作必填 `auditReason`（驳回时必填，通过时可选）。
4. 列表页一律分页；金额类展示两位小数。
