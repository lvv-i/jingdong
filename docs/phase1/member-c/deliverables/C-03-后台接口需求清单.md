## 3. 确认结论（对 A 骨架版的核对结果）

- 骨架版商家组 14 个 + 管理员组 19 个接口，C 全部后台页面均有对应。
- 建议 A-013 全局订单列表支持 `merchantId` 筛选（按店铺查看订单），便于管理员按商家维度追踪。
- 建议 M-009 商家订单列表 list 项含 `userName`（买家昵称脱敏），便于商家联系买家。
- 退款裁决页需要展示商家回复（merchant_reply），A-014 list 已含，确认无误。
