## 执行顺序与依赖

```mermaid
graph LR
    T1[T1 状态机枚举] --> T3[T3 错误码分段]
    T1 --> T4[T4 JWT/RBAC]
    T3 --> T5[T5 接口清单]
    T4 --> T5
    T5 --> T6[T6 定稿签字]
    T2[T2 数据字典] --> T5
    T2 --> T6
```

- **T1 必须 Day 1 完成**：状态机是 B/C/D 页面清单的前置输入，当天需全员签字。
- **T2/T3/T4 可并行**（Day 2），都是契约性文档，互不依赖。
- **T5 依赖 B/C/D 的接口需求清单**（Day 2 提交）与 T1/T3/T4 的定稿结果。
- **T6 依赖全部前序任务**，与 D 协作汇总。
