## 3. 对 B/C/D 的后续提示

1. **接口版本对照**：前端一律以 `05-接口清单v1.0.md` 为准，编号格式 P-/U-/M-/A- 不变。
2. **状态只读约定**：状态机由后端独有，前端只读 `status` 控制按钮显隐，禁止自创状态名。
3. **错误码展示**：HTTP 恒 200，按 `code` 分支提示；`code=1002` 统一跳登录页。
4. **统一返回**：`{code, message, data, total}`；分页 `page/pageSize` + `data.list/data.total`。
5. **测试账号**：按 D-02 方案（user001/merchant001/admin001 等），种子数据由 A 在第二阶段建库脚本提供。

## 4. 第二阶段（后端骨架）预告

- 技术栈：Spring Boot 3.x + MyBatis-Plus + MySQL 8 + JWT（技术选型以启动指导书第 7 节为准）
- 工程结构：controller / service / mapper / entity / config / common（统一返回与异常、JWT 拦截器）
- 实现优先级：登录鉴权 → 商品/类目 → 购物车/订单 → 支付/发货 → 售后 → 评价 → 通知 → 统计
- 交付节奏：先 13 张表建库脚本 + 种子数据（对齐 D-02），再按 T5 接口清单逐个 Controller
