# 05 接口清单 v1.0

> 版本：v1.0（定稿）｜ 作者：成员 A（后端核心）｜ 日期：2026-08-12
> 依据：启动指导书第 6 节 + T1 状态机 + T3 错误码分段表 + T4 JWT/RBAC 方案 + `.qoder/rules/api-contract.md` + B/C/D 接口需求清单
> 状态说明：v1.0 已合并 B/C/D 需求（B-02/C-03/D-01），67 个接口定稿，作为第二阶段编码与联调的合同。

## 0. 通用约定（全体接口）

| 项 | 约定 |
|---|---|
| 统一返回 | `{code, message, data, total}`；code=200 成功；业务错误 HTTP 仍为 200 |
| 分页 | 参数 `?page=1&pageSize=10`（max 100）；data 为 `{list, total}` |
| 鉴权头 | `Authorization: Bearer <token>`（白名单接口除外） |
| 错误码 | 全部来自 T3 错误码分段表；本节仅列主要码 |
| 状态流转 | 涉及流转的接口在"备注"列标注 `from → to`（T1 状态机） |
| 数据范围 | 按 T4 数据权限清单校验；商家接口仅本店数据（shopId） |
