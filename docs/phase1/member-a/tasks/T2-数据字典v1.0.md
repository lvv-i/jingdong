## 覆盖的表（11 张）

| 表 | 用途 | 关键点 |
|----|------|--------|
| users | 用户与登录主体 | 含 role（用户/商家/管理员） |
| merchant_shops | 商家店铺资料 | audit_status、audit_reason |
| categories | 商品类目 | parent_id 树形结构 |
| products | 商品主表 | merchant_id、price、stock、status |
| cart_items | 购物车 | user_id、product_id、quantity、selected |
| orders | 订单主表 | order_no、pay_amount、status |
| order_items | 订单明细 | **title_snapshot、price_snapshot（快照必存）** |
| refund_requests | 退款申请 | **merchant_reply、admin_result（留痕必存）** |
| addresses | 收货地址 | is_default |
| notices | 站内通知 | read_status |
| audit_logs | 操作留痕 | operator_role、target_type、action、remark |

## 工作步骤

1. 读取 `.qoder/rules/db-conventions.md`，列出强制规范：统一字段、命名、类型、软删除、快照、索引、注释。
2. 按 skill `db-dict-generator.md` 的模板为每张表生成字段清单，每列必须含：字段名、类型、是否必填、默认值、中文注释、是否索引。
3. 全表核查：
   - 每张业务表是否都有 id / created_at / updated_at / status / deleted_flag
   - orders/order_items 是否有价格与标题快照；refund_requests 是否有商家回复与管理员处理结果
   - 金额是否 DECIMAL(12,2)；数量/库存是否 INT UNSIGNED；status 是否 VARCHAR(32) 且注释列出全部取值
   - 外键是否加索引；常用查询字段（user_id、merchant_id、order_no、status、created_at）是否加索引
4. 用 skill `db-schema-review.md`（团队共享）自查一遍，修正不合规项。
5. 输出数据字典 v1.0，同步标注版本与日期。
