## 目标

完成商家后台 6 个页面：仪表盘、商品管理（含库存）、订单处理、售后处理、店铺设置，全部对接 M 组接口并遵守 T1 状态机按钮显隐规则。

## 输入依赖

- C2 布局与请求基建
- `docs/phase1/member-a/deliverables/05-接口清单v1.0.md` 商家组（M-001~M-015）
- `docs/phase1/member-a/deliverables/01-状态机枚举表.md`（订单/售后/商品状态流转）
- `docs/phase1/member-c/deliverables/C-01-后台页面清单.md`（6 页蓝图）

## 工作步骤

按页面逐个开发，每页流程：读 C-01 蓝图 → 读 T5 对应接口行 → 读状态机对应章节 → 实现 → 核对验收项。

1. **店铺仪表盘 /merchant/dashboard**：调 M-015 统计接口，卡片展示今日订单数/销售额/待发货数/待处理退款数/商品总数（对应 C-01 的 C-M01）。
2. **商品管理 /merchant/products**：调 M-003~M-007，列表按状态 Tab（草稿/待上架/已上架/已下架）+ 关键字搜索 + 分页；新建/编辑走表单（图片、详情）；DRAFT 显示「提交审核」（M-006）、ON_SALE 显示「下架」（M-007）、仅 DRAFT/OFF_SALE 可编辑（M-005 备注）。
3. **库存管理**：并入商品管理页的「改库存」操作（调 M-008），或独立页 /merchant/stock 快捷改库存。
4. **订单处理 /merchant/orders**：调 M-009~M-011，状态筛选 + 分页；PAID 状态显示「发货」按钮弹运单号表单（M-011，运单号必填）；详情展示买家信息（脱敏）与明细快照。
5. **售后处理 /merchant/refunds**：调 M-012~M-014，REFUNDING 状态显示「同意」（M-013，填回复）与「拒绝」（M-014，回复必填）；历史单据展示 merchant_reply/admin_result 完整结果。
6. **店铺设置 /merchant/shop**：调 M-001/M-002，展示入驻审核状态与审核原因（auditStatus/auditReason）；非 APPROVED 状态编辑按钮置灰并提示（M-002 备注）。

## 产出物

- 文件：`admin-web/src/views/merchant/` 下 6 页 + 对应 `src/api/merchant.js` 接口封装
- 内容：商家后台治理闭环（商品→订单→售后→统计）
- 交付物：`docs/phase4/member-c/deliverables/C3-接口核对表.md`（15/15 接口核对通过）
