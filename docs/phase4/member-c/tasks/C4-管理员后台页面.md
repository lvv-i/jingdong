## 目标

完成管理员后台 7 个页面：审核中心、类目管理、商品巡检、商家管理、用户管理、争议处理、日志统计，全部对接 A 组接口，覆盖平台治理闭环。

## 输入依赖

- C2 布局与请求基建
- `docs/phase1/member-a/deliverables/05-接口清单v1.0.md` 管理员组（A-001~A-019）
- `docs/phase1/member-a/deliverables/01-状态机枚举表.md`（商家入驻/商品/售后状态）
- `docs/phase1/member-c/deliverables/C-01-后台页面清单.md`（7 页蓝图）

## 工作步骤

1. **审核中心 /admin/audit**：
   - 商家入驻审核：A-001 列表（按 auditStatus 筛选），PENDING_AUDIT 显示「通过」（A-002，auditReason 可选）与「驳回」（A-003，auditReason 必填）。
   - 商品上架审核：A-010 列表（仅 PENDING_ON_SALE），显示「通过」（A-011）与「驳回」（A-012，驳回回 DRAFT）。
2. **类目管理 /admin/categories**：A-004~A-007，类目树 + 增改启停；软删除且有商品时展示后端拒绝提示（A-007 备注）。
3. **商品巡检 /admin/products**：A-008 全局商品列表（含商家名）+ 关键字/状态筛选；ON_SALE 显示「强制下架」（A-009，auditReason 必填）。
4. **商家管理 /admin/merchants**：复用 A-001（auditStatus=APPROVED 筛选），展示店铺列表与状态。
5. **用户管理 /admin/users**：A-016 列表（keyword/role 筛选）+ A-017 禁用/启用（操作需二次确认）。
6. **争议处理 /admin/refunds**：A-014 全局退款列表（展示 merchant_reply）；ADMIN_INTERVENED 状态显示「裁决」弹窗（A-015：同意退款 / 驳回关闭，adminResult 必填）。
7. **日志统计 /admin/logs**：A-018 审计日志查询（operatorRole/targetType 筛选）；A-019 全局统计卡片（用户/商家/商品/订单/退款数、销售额）。

## 产出物

- 文件：`admin-web/src/views/admin/` 下 7 页 + 对应 `src/api/admin.js` 接口封装
- 内容：平台治理闭环（入驻审核→上架审核→巡检下架→退款裁决→日志留痕）
