## 工作步骤

1. **按钮显隐核查**：逐页对照 T1 状态集合与合法流转，列出每个页面"状态 → 可见按钮"映射表，输出到 `deliverables/C5-状态按钮映射表.md`。
   - 商家侧示例：订单 PAID→发货；商品 DRAFT→提交审核、ON_SALE→下架；售后 REFUNDING→同意/拒绝。
   - 管理员侧示例：商家 PENDING_AUDIT→通过/驳回；商品 PENDING_ON_SALE→通过/驳回；ON_SALE→强制下架；售后 ADMIN_INTERVENED→裁决。
2. **禁止流转核查**：确认页面不会出现 T1 禁止清单中的操作入口（如已发货订单不可取消、已上架商品不可直接编辑）。
3. **越权提示核查**：对照 C-02 第 3 节越权返回约定，确认 1002/1003/6xxx/7xxx 在页面上有对应中文提示；商家登录后尝试访问 /api/admin/**（手动构造请求）被拦截且提示友好。
4. **三方协作链路自测**（配合 D 的演示路径，先用种子数据演练）：
   - 商家入驻：商家申请 → 管理员审核通过/驳回（审核原因留痕展示）
   - 商品链路：商家发布草稿 → 提交审核 → 管理员通过 → 上架；商家/管理员下架
   - 履约链路：用户下单支付 → 商家发货（运单号）→ 用户确认收货
   - 退款链路：用户申请 → 商家同意/拒绝 → 商家拒绝后用户申请平台介入 → 管理员裁决 → 结果三方可见
5. 用 browser-use 逐页截图验证交互，记录问题清单并修复，输出 `deliverables/C5-交互验收清单.md`。
