> 成员 C ｜ 计划 Day 1 ｜ 状态：✅ 已完成（2026-08-15）
> 关联 skill：`.qoder/members/member-c/skills/admin-page-dev.md`

## 目标

初始化后台共用工程 `admin-web/`（商家 + 管理员共用一个 Vue 3 工程，按角色分菜单），跑通开发环境。

## 输入依赖

- 《电商项目团队分工与公共配置方案》3.1 节（技术栈与工程结构）
- `.qoder/skills/frontend-component-guide.md`（团队共享，组件/表单/分页写法）
- `.qoder/rules/code-style.md`（Vue 命名、注释、目录规范）

## 工作步骤

1. 用 Vite 创建 Vue 3 工程：`admin-web/`（TypeScript 可选，团队基线以能跑通为先）。
2. 安装依赖：`element-plus`、`vue-router`、`pinia`、`axios`；按需引入 Element Plus 或全量引入（工程型项目选按需）。
3. 建立目录骨架：
   - `src/api/`（接口封装，按 T5 分组：`merchant.js`/`admin.js`/`auth.js`）
   - `src/router/`（路由表 + 角色守卫）
   - `src/stores/`（Pinia：user/merchant/admin）
   - `src/views/merchant/`（6 页目录）、`src/views/admin/`（7 页目录）、`src/views/login/`
   - `src/components/`（公共组件：状态标签、分页表格等）
   - `src/utils/`（request 封装、常量、状态映射表）
4. 配置 dev 代理：`/api` → `http://localhost:8080`（后端端口，以 `backend/src/main/resources/application.yml` 为准）。
5. 建立统一请求封装 `src/utils/request.js`：baseURL、Bearer token 注入、`{code,message,data,total}` 统一解包、错误码→提示文案映射（对齐 T3 错误码分段表）。

## 产出物

- 文件：`admin-web/` 工程骨架（可 `npm run dev` 启动）
- 内容：目录骨架 + 依赖 + 代理配置 + 请求封装雏形

## 验收标准

- [x] `npm run dev` 启动无报错，浏览器可打开默认页
- [x] `src/` 目录按 rule 规定分层，views 下 merchant/admin/login 目录齐备
- [x] `/api` 代理指向后端端口，可连通 A 的白名单接口（如 GET /api/categories 返回 code:200）——代理已配置，真实连通待 M3（MySQL 环境）
- [x] request 封装已含 token 注入与错误码解包雏形
