## 3. 契约模糊点（已按 T1 状态机兼容处理，无需反馈 A）

- **M-002 备注"非 APPROVED 状态不可编辑"与 T1 3.2"REJECTED → PENDING_AUDIT（商家修改资料后重新提交）"存在张力**：
  - T5 无独立的"重新提交入驻"接口，T1 明确 REJECTED 商家可修改重提。
  - 前端处理：REJECTED 状态渲染「修改并重新提交」按钮（调 M-002）；若后端按 M-002 备注拒绝（6005），错误码文案即为"店铺已被驳回，请修改资料重新提交"，页面横幅同步引导，不会裸弹错误码。
  - PENDING_AUDIT 状态不渲染编辑按钮（6003 明确禁止）。
- **商品图片无上传接口**：T5 无文件上传接口，表单采用图片 URL 输入（主图必填、轮播图可选），与 M-003/M-005 的 mainImage/images 字符串字段一致。
