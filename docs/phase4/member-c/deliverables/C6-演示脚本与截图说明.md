## 演示路线总览（配合 D 演示路径，后台侧视角）

```
管理员 admin001：审核中心（入驻/上架审核）→ 类目管理 → 商品巡检 → 争议处理 → 日志统计
商家 merchant001：店铺仪表盘 → 商品管理 → 订单处理 → 售后处理
三方联动：入驻审核 → 上架审核 → 发货 → 退款裁决（深度分支）
```

## 场景一：商家入驻审核闭环（管理员）

| 步骤 | 操作 | 预期画面 | 截图位 |

| 2 | 点击「通过」→ 填写审核意见（可选） | 弹窗提交 → 列表刷新为 APPROVED | 图 2 |
| 3 | 另一条点击「驳回」→ 原因必填校验 | 原因为空时提交被拦截（前端校验） | 图 3 |
| 4 | 商家 merchant001 登录 → 店铺设置 | 展示驳回横幅 + 审核原因 +「修改并重新提交」按钮 | 图 4 |
| 5 | 商家修改重提 | 状态回 PENDING_AUDIT，管理员端可见 | 图 5 |
