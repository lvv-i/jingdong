## 2. 重点核对项（易错清单）

| 易错点 | 核对结果 |
|---|---|
| 分页参数 page/pageSize、返回 {list, total} | ✅ 全部列表页对齐 |
| 审核原因 auditReason：驳回必填、通过可选 | ✅ A-003/A-009/A-012 必填校验；A-002/A-011 可选 |
| 裁决 adminResult + agree 布尔必填（A-015） | ✅ 双字段校验 |
| 金额两位小数（refundAmount/salesAmount） | ✅ toFixed(2) |
| 状态值枚举字符串 | ✅ 引用 status.js |
| 敏感操作二次确认（A-009 强制下架/A-015 裁决/A-017 禁用） | ✅ 均 ElMessageBox.confirm |
| 审计留痕说明（写 audit_logs） | ✅ 弹窗/确认文案提示"操作写入审计日志" |
