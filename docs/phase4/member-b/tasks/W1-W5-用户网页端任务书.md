- [ ] 统一返回处理：HTTP 200 时按 `{code, message, data, total}` 解包；`code=200` 成功，否则按 T3 只展示后端 `message`

- [ ] 分页一律 `?page&pageSize`（max 100），取 `data.list` + `data.total`
- [ ] 登录后请求统一带 `Authorization: Bearer <token>`（Axios 拦截器注入）
- [ ] 提交类按钮点击后 loading 防重复提交（后端 1006 兜底）
- [ ] 前端只读 T1 状态名，不自创；按钮显隐由后端返回状态驱动
