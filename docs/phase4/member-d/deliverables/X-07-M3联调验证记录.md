## 4. 缺陷发现与修复（H2 中文乱码）

**现象**：H5 页面所有数据库中文（类目名/商品名/地址）显示乱码（如"数码家电"→"鏁扮爜瀹剁數"）。

**根因**：`backend/src/main/resources/application-h2.yml` 缺少 `spring.sql.init.encoding: UTF-8`，Windows 中文环境按 GBK 读取 UTF-8 的 `h2-schema.sql` / `h2-seed.sql`，入库即乱码（代码硬编码的 message 不受影响，故此前 C 联调只测错误码未暴露）。

**修复**：
1. `application-h2.yml` 增加 `encoding: UTF-8`
2. 删除 H2 数据文件 `backend/data/jd_shop.mv.db`，重启后端重新初始化
3. 验证：`GET /api/categories` 返回"数码家电/手机通讯/男装"正确中文 ✅

**注意**：H2 数据重建后，种子数据恢复到初始状态（联调产生的订单/退款/日志清零，种子订单与地址仍在）。
