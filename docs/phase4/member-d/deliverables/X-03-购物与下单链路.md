### 3. 结算页（`pages/checkout/checkout.vue` 新建，pages.json 注册）

- U-003 地址选择：内联 radio 列表、默认地址优先选中、「默认」标签；无地址引导「去『我的』添加地址」；无地址提交 toast「请先选择收货地址」

- U-012 提交：submitting 防重复；成功后进入拆单成功态（按 T5 U-012 响应 {orders:[...]} 逐单展示订单号/金额/去支付），并清空 storage 勾选 id（购物车项由后端移除，前端 onShow 自动刷新）
- 失败处理（按 T3 后端实际错误码）：4003 购物车为空 → 提示后返回购物车；4004 已下架 / 4005 库存不足 / 4006 价格变化 → 提示后自动刷新结算清单；2005/2006 地址无效 → 请求层 toast 提示；4007 校验失败 → toast 后端 message
