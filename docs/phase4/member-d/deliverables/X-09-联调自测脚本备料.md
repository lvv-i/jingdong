## 3. 三端闭环演示脚本（答辩用，10 分钟）

1. **用户端/移动端**：user001 登录 → 浏览 → 加购 → 下单 → 支付（PAID）
2. **商家后台**：merchant001 登录 → 订单列表 → 发货（SHIPPED）→ 演示商家售后拒绝（M-014）
3. **用户端/移动端**：确认收货（COMPLETED）→ 评价 → 发起退款 → 申请介入
4. **管理员后台**：admin001 登录 → 退款列表 → 裁决同意（REFUNDED）→ 审计日志展示 3 条留痕
5. **管理员后台**：入驻审核（merchant002 店铺通过/驳回）、商品上架审核、日志统计页
6. **移动端**：消息已读、地址增删改默认、个人资料
