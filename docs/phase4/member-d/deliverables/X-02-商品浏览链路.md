### 3. 商品卡片组件（`src/components/product-card/product-card.vue` 新建）

- 图片 `lazy-load` 懒加载 + `@error` 失败占位（/static/logo.png）
- 标题两行截断、现价 + 划线原价、销量格式化（1.2万+）
- 首页 / 分类页 / 搜索结果共用

### 4. 首页（D-P01 `pages/index/index.vue` 重写）

- 搜索入口：跳分类页并聚焦搜索框（storage 一次性消费标记，D-01 无独立搜索页）
- 类目宫格：P-003 顶级类目前 8 个（sortOrder 升序），点击跳分类页并预选该类目
- 热销商品：P-004 sort=sales，`onReachBottom` 触底分页，空状态「暂无商品，敬请期待」

### 5. 分类页（D-P02 `pages/category/category.vue` 重写）

- 左侧类目树（P-003 顶级）+ 右侧子类目标签（parentId 分组，「全部」）
- 商品列表 P-004：categoryId 筛选（后端含子类目）+ keyword 搜索 + sort 四档切换（综合/销量/价格↑/价格↓，对应 空/sales/priceAsc/priceDesc）
- 首页带入类目预选；加载时序修复（类目树就绪后再驱动首屏商品，避免请求全量）
- 空状态区分：搜索无结果「没有找到相关商品」/ 分类无商品「该分类暂无商品」

### 6. 商品详情（D-P03 `pages/product/detail.vue` 新建，pages.json 注册）

- P-005：主图轮播（mainImage + images 多图，单图失败占位）、价格 + 划线原价、标题/副标题、销量/库存/店铺名、detail 富文本（rich-text）
- 错误兜底：3001「商品不存在」/ 3002「商品已下架」→ 警示页 + 返回/回首页
- P-006 评价列表：userName 脱敏直接展示、星级 ★ 渲染、评论 + 时间、分页「加载更多评价」、空状态
- U-009 加购：未登录 → toast「请先登录」+ 跳登录页；缺货按钮禁用「暂时缺货」；防重复提交
- 底部操作栏 `env(safe-area-inset-bottom)` 安全区适配

### 7. 公共格式化工具（`src/utils/format.js` 新建）

- formatPrice（BigDecimal 兼容）、formatPriceWithComma、formatDateTime（LocalDateTime 字符串）、formatSales
