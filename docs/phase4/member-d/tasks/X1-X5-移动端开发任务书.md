## 通用契约约定（全部任务共同遵守）

- [ ] 统一响应处理：HTTP 200 时取 `{code, message, data, total}`，仅 `code=200` 为成功；错误只按 T3 展示 `message`
- [ ] `code=1002` 全局跳登录页；2001~2005 在登录/注册/验证码页特殊文案
- [ ] 分页一律 `?page&pageSize`（max 100），取 `data.list` + `data.total`
- [ ] 登录态请求统一注入 `Authorization: Bearer <token>`（请求拦截器）
- [ ] 提交类按钮加 loading 与防重复提交（幂等防 4008 等）
- [ ] 前端只读 T1 状态机：按钮显隐完全由后端返回状态驱动，不自创状态名
- [ ] 空数据状态必须给提示，不空白不报错（P1 验收项）
- [ ] 端差异只在适配层处理（条件编译），页面业务逻辑三端共享
