# mcp: browser-use-guide（C 的 MCP 使用约定）

> 成员 C 专属 ｜ 团队 MCP（browser-use / genui）如何服务于 C 的后台页面验收（C5/C6）

## browser-use（逐页验证交互）

**使用场景**：C3/C4 页面开发完成后，C5/C6 阶段逐页自动化验证；发现 UI 问题时的复现与截图留档（供实验报告"使用示例"部分）。

**约定步骤**：

1. 启动前端 `npm run dev` + 后端服务（或由 A 提供联调地址）。
2. 让 AI 打开页面（浏览器 MCP），按以下脚本验证：
   - 登录 merchant001 → 检查菜单只有商家 6 项 → 走商品发布/提交审核/发货/退款处理
   - 登录 admin001 → 检查菜单只有管理员 7 项 → 走入驻审核/上架审核/裁决退款
   - 越权验证：商家登录态下直接访问 `/admin/orders` 路由 → 应被拦截
3. 每页验证结果截图 + 文字说明（截图配详细文字，对应作业评分"使用示例"要求）。
4. 发现的问题写入 C5 交互验收清单，修复后重新验证并标注闭环。

**注意**：验证时优先使用 seed.sql 固定数据（D-02 演示路径），保证可复现。

## genui（原型参考）

**使用场景**：页面开发前如需界面原型参考（仪表盘卡片布局、审核弹窗、类目树），可让 genui 生成原型组件，再按 Element Plus 落地实现。

**约定**：genui 仅作视觉参考，最终代码必须走 Element Plus + 本工程 `src/utils/status.js` 状态映射，不直接引用 genui 产物。
