# Skill (B专属): 用户端页面规格生成

## Description

指导成员 B 按 B-01 页面清单（13 页）生成/审查用户网页端页面：确定每页的组件选型、数据来源（T5 接口编号）、交互流程、状态机依赖与空状态/错误处理，输出可直接指导编码的页面规格。

## When to Use

- 第四阶段 W2-W5：每开发一个页面组前，先产出该页的页面规格
- 审查已写页面是否与 B-01/T5/T1 契约一致
- 全链路自测前逐页核对空状态与错误提示覆盖

## 输入（每次生成前必读）

1. `docs/phase1/member-b/deliverables/B-01-用户端页面清单.md`（13 页 + 交互约定）
2. `docs/phase1/member-a/deliverables/05-接口清单v1.0.md`（对应接口编号的请求/响应/错误码）
3. `docs/phase1/member-a/deliverables/01-状态机枚举表.md`（页面涉及的状态与合法流转）
4. `.qoder/skills/frontend-component-guide.md`（组件选型基线）

## 输出模板（每页一份）

### 1. 页面定位

| 项 | 内容 |
|----|------|
| 编号/路由 | 如 B-P03 `/product/:id` |
| 所属任务 | 如 W2 |
| 页面职责 | 一句话 |

### 2. 数据来源

| 数据块 | 接口 | 触发时机 | 加载态/空态/错误态 |
|--------|------|----------|--------------------|
| 商品主图 | P-005 | onMounted | loading / `暂无商品` / 3001、3002 文案 |

### 3. 交互流程（按用户动作展开）

| 操作 | 前置条件 | 调用接口 | 成功后行为 | 失败分支（错误码 → 处理） |
|------|----------|----------|------------|---------------------------|
| 加购 | 已登录、ON_SALE | U-009 | toast + 购物车角标刷新 | 3002 已下架提示 / 1002 跳登录 |

### 4. 状态机依赖（只读 T1，不自创状态）

| 状态值 | 展示 | 可用按钮 |
|--------|------|----------|
| PENDING_PAY | 待支付（warning） | 支付 U-015 / 取消 U-016 |

### 5. 组件选型（Element Plus）

表格、表单、分页、标签、对话框等，标注关键 props（如 `el-pagination` 的 `layout="total, prev, pager, next"`）。

### 6. 验收要点

- 分页参数 `page/pageSize`，取 `data.list` + `data.total`
- 提交类按钮 loading 防重复
- 空数据有提示不空白（P1）
- 业务错误统一按 `code` 分支提示

## 审查清单

1. 页面路由与 B-01 清单一致，无自造页面
2. 每个数据块都有对应 T5 接口编号，无自造接口
3. 状态展示值与 T1 完全一致，按钮显隐由后端返回状态驱动
4. 错误码处理覆盖该接口备注列全部主要错误码
5. 空态/加载态/错误态三态齐全

## Output Format

按上述 6 部分输出页面规格；多页共用组件（商品卡片、状态标签、空态组件）单独列「公共组件」表。
# Skill (B专属): 用户端页面生成与审查

## Description

指导成员 B 按 B-01 页面清单（13 页）生成/审查用户网页端页面：每页写明布局结构、组件选型（Element Plus）、接口绑定、状态依赖与空状态处理，确保页面实现与 T1 状态机、T3 错误码、T5 接口清单严格对齐。

## When to Use

- 第四阶段 W2-W5 每个页面开发前生成页面规格
- 页面完成后的自审与团队评审
- 需要复用组件（商品卡片、订单状态标签）时

## 输入处理流程

1. 读取 B-01 页面清单，确定页面编号、路由、关键内容
2. 读取 T5 接口清单，确定该页所需接口（编号/参数/响应/错误码）
3. 读取 T1 状态机，确定该页涉及的按钮显隐规则（只读后端状态）
4. 读取 `.qoder/rules/code-style.md`，按 Vue 规范落代码
5. 按下方模板产出页面规格，再实现

## 页面规格模板

| 项 | 内容 |
|----|------|
| 页面编号/路由 | B-Pxx / 路由路径 |
| 布局结构 | 顶部导航 / 主体分区 / 分页 |
| 组件选型 | Element Plus 组件（el-table/el-pagination/el-empty...） |
| 接口绑定 | T5 编号 + 参数 + 成功处理 + 错误码处理 |
| 状态依赖 | 涉及 T1 状态时：仅 X 状态显示按钮 Y |
| 空状态 | 无数据时 el-empty 文案（对应 P1 验收项） |

## 页面清单（B-01 v1.0，13 页）

| 编号 | 页面 | 路由 |
|---|---|---|
| B-P01 | 首页 | `/` |
| B-P02 | 搜索/列表页 | `/search` |
| B-P03 | 商品详情 | `/product/:id` |
| B-P04 | 登录/注册 | `/login` |
| B-P05 | 购物车 | `/cart` |
| B-P06 | 结算页 | `/checkout` |
| B-P07 | 订单中心 | `/orders` |
| B-P08 | 订单详情 | `/orders/:id` |
| B-P09 | 售后中心 | `/refunds` |
| B-P10 | 评价 | `/orders/:id/review` |
| B-P11 | 个人中心 | `/profile` |
| B-P12 | 地址管理 | `/addresses` |
| B-P13 | 消息通知 | `/notifications` |

## 审查清单

1. 页面路由与 B-01 一致；不越界实现商家/管理员功能
2. 接口调用与 T5 编号/参数/响应字段完全一致，不猜测字段
3. 按钮显隐由后端返回状态驱动，不写死、不自创状态名
4. 错误码只按 code 展示 message；1002 跳登录；2001~2004 特殊文案
5. 空状态覆盖：每个列表/详情页无数据有 el-empty 提示
6. 提交类按钮有 loading 防重复提交
7. 分页统一 page/pageSize，取 data.list + data.total
