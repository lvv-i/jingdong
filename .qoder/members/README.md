# .qoder 成员专属配置说明

## 配置分层（两类，勿混淆）

| 层级 | 目录 | 适用范围 | 维护人 |
|------|------|----------|--------|
| **团队共享** | `.qoder/skills/`、`.qoder/rules/`、`.qoder/mcps/` | 全体成员，任何人工作都必须遵守 | D（公共配置负责人） |
| **成员专属** | `.qoder/members/<member-x>/skills|rules|mcps/` | 仅该成员本人使用，不影响他人 | 各成员自己 |

## 目录结构

```
.qoder/
├── skills/            # 团队共享 skills（5 个）
├── rules/             # 团队共享 rules（5 个）
├── mcps/              # 团队共享 MCP 说明（2 个）
└── members/           # ★ 成员专属配置（新增，本层为成员个人工作区）
    ├── README.md      # 本文件
    └── member-a/      # 成员A（后端核心）专属
        ├── README.md  # A 专属配置索引
        ├── skills/    # A 专属技能（仅 A 使用）
        ├── rules/     # A 专属规则（仅 A 使用）
        └── mcps/      # A 的 MCP 使用约定（团队 MCP 如何服务于 A）
```

## 使用约定

1. **团队共享配置**：所有人必须遵守，修改需经 D 统一更新（见分工方案第七章）。
2. **成员专属配置**：本人按需创建/修改，提交到 Git 后他人可读但**不强制执行**；其他成员工作时不加载该目录。
3. AI 协作时，成员提示 AI 读取自己的专属目录（如"读取 `.qoder/members/member-a/` 下的配置"），避免互相干扰。
4. 若某成员专属配置被证明有普遍价值，由 D 评审后提升为团队共享配置。
