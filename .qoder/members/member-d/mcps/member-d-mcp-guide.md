# MCP 使用指南 (D专属): genui 与 browser-use 在移动端的用法

> 团队共享 MCP 说明见 `.qoder/mcps/genui.md` 与 `.qoder/mcps/browser-use.md`；本文件记录成员 D 在移动端场景下的使用约定。

## genui（UI 原型生成）

用途：生成/预览移动端页面 UI 原型，与网页端保持京东风格一致。

- 第四阶段 X2 前：先用 genui 出首页/商品详情/购物车的移动端布局原型，确认配色与交互后再落地 uni-app 代码
- 风格约定：京东红主色、卡片式列表、底部操作栏；移动端页面窄屏适配
- 产出截图存入对应交付物文档（如 `X-02-商品浏览链路.md`），配文字说明（作业评分「使用示例」要求截图必须配文字）

## browser-use（端到端验证）

用途：验证 H5 端页面交互与后端联调结果。小程序/App 原生能力无法用 browser-use 验证，统一以 H5 构建产物验证业务逻辑，端差异仅检查条件编译分支。

- X1 后：验证登录/注册（含验证码 123456 流程）
- X3 后：验证 加购 → 下单 → 模拟支付 全链路（user001）
- X4 后：验证订单按钮显隐（各状态）、售后申请/撤销/介入、消息已读
- X5：全页面巡检：空状态、错误提示、无报错
- 每次验证截图存档到对应交付物文档

## 注意事项

1. browser-use 验证需要后端在 `http://localhost:8080` 运行（MySQL 8 就绪后，里程碑 M3）。
2. 后端未就绪时，先用 genui 做 UI 原型与静态页面开发，接口联调后置。
3. 验证发现的 bug 记录到联调记录（接口编号/现象/期望），A 修复后回归验证。
