# Skill (D专属): 测试基线与 AI 交互记录

## Description

指导成员 D 按 T1 状态机与 D-02 测试账号方案生成测试用例、演示脚本与 AI 交互记录（对应作业评分：测试 20 分 + 交互过程 30 分）。D 兼任测试/文档职能，本 skill 覆盖第四阶段自测与第五阶段全端回归。

## When to Use

- 第四阶段 X5 全链路自测、测试用例整理
- 第五阶段牵头全端回归测试、联调验收
- 每次与 AI 协作开发时记录交互过程

## 测试用例生成（按 T1 状态机三向覆盖）

1. **正向流转**：订单 PENDING_PAY→PAID→SHIPPED→COMPLETED；售后 REFUNDING→MERCHANT_AGREED→REFUNDED 等全部合法流转
2. **负向流转**：非法流转期望后端拒绝（如 COMPLETED 订单取消 → 期望 1001/4002；REFUNDING 直接平台介入 → 期望 5005）
3. **边界条件**：库存 0 下单（4006）、退款金额超实付（1001）、地址超 20 个（2006）、重复支付（4008）、60 秒验证码限频（1007）

权限测试按 C-02 权限矩阵：未登录访问用户接口（1002）、用户访问商家接口（1003 或拦截）。
