# Skill (D专属): uni-app 移动端页面生成与审查

## Description

指导成员 D 按 D-01 页面清单（9+2 页）生成/审查 uni-app（Vue 3 + Vite）移动端页面，一套代码输出 App + 微信小程序 + H5，端差异只在适配层处理。

## When to Use

- 第四阶段 X2-X5：生成首页/分类/详情/购物车/订单/消息/我的/售后/登录等页面
- 页面审查：检查是否违反 T1 状态机只读、空状态、按钮显隐规则

## 页面生成流程

1. 读取 D-01 页面清单对应页面说明与 T5 接口清单对应接口（编号/参数/响应/错误码）
2. 确定页面路由（pages.json 注册）与 tabBar 归属
3. 按页面模板产出：数据加载（onLoad/onShow 生命周期）、状态驱动渲染、按钮显隐逻辑、空状态/错误态
4. 端差异点用条件编译包裹（`#ifdef H5` / `#ifdef MP-WEIXIN` / `#ifdef APP-PLUS`）

## 页面输出模板要点

- **数据流**：页面内 `api/` 模块函数 → onLoad 拉取 → data 渲染；分页用 page/pageSize，onReachBottom 触底加载
- **按钮显隐**：只读 T1 状态值驱动（如 `v-if="order.status==='PENDING_PAY'"` 显示支付/取消），禁止自创状态名
- **空状态**：list 为空时展示「暂无数据」占位组件，禁止空白页
- **错误处理**：code≠200 时 toast 展示 message；1002 跳登录页
- **组件复用**：商品卡片、订单卡片、退款卡片、空状态组件全局注册复用

## 条件编译约定（适配层）

- 安全区：底部操作栏在 APP/H5 用 `env(safe-area-inset-bottom)`；小程序用 `safe-area-inset-bottom` 常量的 `::after` 占位
- 登录方式：App/小程序主推短信验证码（P-007/P-008）；H5 补充账号密码（P-002）
- 图片：本地 static 与远程 URL 统一走 image 组件 + 失败占位图

## 审查清单

1. 页面与 D-01 清单编号对应，无遗漏无自创页面
2. 接口编号与 T5 一致，请求参数/分页/错误码处理正确
3. 按钮显隐只依赖后端状态，无前端自造状态判断
4. 空状态/加载态/错误态三态齐全
5. 端差异代码只出现在适配层，业务逻辑三端共享
