启动方式（更新：2026-08-30，含局域网访问）

方式一：一键启动（推荐，答辩用）
双击根目录 start-all.bat，自动完成：防火墙放行 → MySQL → 后端 8080 → 用户网页端 5173 → 后台端 5174 → 移动端 H5 5175；按任意键全部停止。

方式二：手动分步启动

① 网页版（用户商城）——浏览器访问 http://localhost:5173
cd d:\Desktop\jingdong\frontend-user
npm install        （首次）
npm run dev -- --port 5173

② 商家/管理员后台——浏览器访问 http://localhost:5174
cd d:\Desktop\jingdong\admin-web
npm install        （首次）
npm run dev -- --port 5174

③ 软件版（App/小程序，uni-app 一套代码）
H5 版（浏览器模拟手机访问）：http://localhost:5175
cd d:\Desktop\jingdong\mobile-app
npm install        （首次）
npm run dev:h5

微信小程序版（先按方式一/二启动后端）：
cd d:\Desktop\jingdong\mobile-app
npm run build:mp-weixin
然后用微信开发者工具导入 d:\Desktop\jingdong\mobile-app\dist\build\mp-weixin 目录运行（或双击 rebuild-mp.bat 重建产物）

④ 后端 API：
cd d:\Desktop\jingdong\backend
java -jar target\jd-shop-1.0.0.jar   （8080 端口；没有 MySQL 时加 --spring.profiles.active=h2 用内嵌库）
MySQL 8：脚本会自动检查 D:\mysql-8.0.28-winx64 并拉起（3306）

方式三：局域网访问（同一 WiFi/校园网内的其他电脑访问）
1. 本机查 IP：cmd 输入 ipconfig，记下 IPv4 地址（如 192.168.1.100）
2. 其他电脑浏览器打开（需本机防火墙放行，start-all.bat 已自动尝试添加规则）：
   - 用户网页端：http://192.168.1.100:5173
   - 商家/管理员后台：http://192.168.1.100:5174
   - 移动端 H5：http://192.168.1.100:5175（API 自动指向 http://192.168.1.100:8080）
3. 无法访问时：以管理员身份运行
   netsh advfirewall firewall add rule name=JDShop dir=in action=allow protocol=TCP localport=5173
   （5174/5175/8080 同理），或在"Windows Defender 防火墙 → 高级设置 → 入站规则"手动放行
4. 公网（跨网络）访问需内网穿透（frp/ngrok），不在本项目范围
